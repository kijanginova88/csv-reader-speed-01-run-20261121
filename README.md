A fast drop-in replacement for make.fun's csv-reader 1.0.0: it reads broken CSV files exactly as the reference does — BOM, CRLF, stray CRs, unterminated quotes, quote junk, short and long rows, all reported the same way — but several times faster, using native string scans, a line-based fast path, and quoted fields sliced out whole.

## Run it

```sh
node main.ts
```
